# Artifact System V6

This is a source-location guide, not a generated balance mirror.

- Authored artifacts, rank costs, rank effects, milestones, and special effects: `src/game/content/artifacts/artifacts.ts`
- Rank ownership, eligibility, purchasing, effective stats, and active combat providers: `src/game/systems/artifacts/artifactProgression.ts`
- Cumulative and next-rank presentation: `src/game/presentation/artifacts/artifactPresentation.ts`
- Artifact Path layout and graph read model: `src/game/presentation/artifacts/artifactPathReadModel.ts`
- Player-facing Path UI: `src/components/artifacts/`

The V5 Markdown artifact document is historical and deprecated. Runtime TypeScript remains authoritative.

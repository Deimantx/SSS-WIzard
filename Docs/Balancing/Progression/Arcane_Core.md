# Arcane Core

Permanent specialization replaces the removed jewelry layer. Core Points unlock nodes; Arcane Essence purchases deterministic ranks.

## Branches

| Branch | ID | Purchasable nodes | Ranks per node |
| --- | --- | --- | --- |
| Power | power | 64 | 5 |
| Vitality | vitality | 64 | 5 |
| Focus | focus | 64 | 5 |
| Control | control | 64 | 5 |

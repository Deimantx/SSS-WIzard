# Progression overview

| Dungeon | Unlock | Boss |
| --- | --- | --- |
| Whispering Woods | Available from the start | Forest Heart (forest-heart) |
| Howling Den | Defeat Forest Heart | Corrupted Greatbear (corrupted-greatbear) |
| Abandoned Catacombs | Defeat Corrupted Greatbear | Archmage Edrin's Shade (archmage-edrin-shade) |

## Persisted milestones

- firstBossKill - first dungeon boss milestone
- firstMainBossKill - legacy Forest Heart milestone
- guildUnlocked - Guild feature gate
- emberStaffUnlocked - Ember Staff progression marker
- forestHeartUnlocked - Forest Heart progression marker
- autoHuntBossUnlocked - boss auto-hunt gate
- magicLevelCap - current school level ceiling (20 initially, 40 after the tutorial)
